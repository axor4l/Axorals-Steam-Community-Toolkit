# Steam Toolkit v0.6.0

Visual overhaul of v0.5.0. Existing module names and scanner behavior are preserved.

## UI changes
- Retro Steam / terminal visual system
- CRT scanline treatment
- Animated launcher, panel opening, tabs, buttons and result transitions
- Terminal-style status console and progress indicator
- Redesigned Collector Scanner dashboard and result cards
- Matching visual treatment for REP Scanner and Group Collector result windows
- Reduced-motion support

## Modules
- Collector Scanner
- REP Scanner
- Group Collector
- High Value Items
